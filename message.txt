FIXED AUDIO ARCHITECTURE
============================================================

For PyTorch, you may use the available musicnn-pytorch implementation if it is reliable and compatible.

TRANSFORMER
============================================================

Implement a custom Transformer ENCODER for temporal modeling.

Fixed architecture:

    input dimension = 128

    feed-forward dimension = 512
    dropout = 0.1
    activation = GELU

Use PyTorch's TransformerEncoder / TransformerEncoderLayer.

Use:

    batch_first=True

Use LayerNorm.

Use positional encoding before the Transformer.

Prefer sinusoidal positional encoding so there are no additional learned positional parameters.

Architecture:

    [B, 4, 128]
          |
    positional encoding
          |
    Transformer Encoder
      4 layers
      8 heads
      d_model 128
      FFN 512
      GELU
      dropout 0.1
          |
    [B, 4, 128]
          |
    mean pooling over temporal dimension
          |
    [B, 128]

This 128-D vector is the Transformer representation.

Do NOT reduce it before the Transformer.

Do NOT use only one token.

The purpose of the Transformer is to model relationships between the four 3-second musicnn representations.

============================================================
VAE
============================================================

Implement a VAE operating on the 128-D Transformer representation.

Input:

    [B, 128]

Latent dimension:

    64

Encoder:

    128
      |
    Linear
      |
    LayerNorm
      |
    GELU
      |
    128 hidden units
      |
    +------------------+
    |                  |
    Linear -> mu       Linear -> log_var
    |                  |
    64                 64

Use the standard reparameterization trick:

    std = exp(0.5 * log_var)
    eps = random normal
    z = mu + eps * std

Therefore:

    z = [B, 64]

Decoder:

    64
      |
    Linear
      |
    LayerNorm
      |
    GELU
      |
    128
      |
    Linear
      |
    128

The VAE reconstructs the Transformer's 128-D representation.

Therefore:

    input to VAE       = [B, 128]
    reconstruction     = [B, 128]
    mu                 = [B, 64]
    log_var            = [B, 64]
    z                  = [B, 64]

============================================================
VAE LOSS
============================================================

Implement:

    reconstruction_loss = MSE(reconstruction, target)

and:

    KL =
        -0.5 * mean(
            1 + log_var
            - mu^2
            - exp(log_var)
        )

Total:

    total_loss =
        reconstruction_loss
        + beta * KL

Make beta configurable.

Default:

    beta = 1.0

Do NOT hard-code beta in multiple places.
